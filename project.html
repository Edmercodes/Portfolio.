AquaTrack: AI-Integrated Mobile App and Web System

A capstone project developed for Caraga State University that modernizes water refilling station operations in Butuan City. AquaTrack combines a React Native mobile app, a React web system, and an AI-powered detection model to manage inventory and track gallon containers efficiently.

The system enables real-time monitoring, demand forecasting, and automated data management through an integrated backend powered by Supabase and Python-based AI detection.
